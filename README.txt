LYSINDER PORTFOLIO DASHBOARD — QUICK START

1. Open index.html in a modern browser to preview the website locally.
2. Before publishing, search in index.html for YOUR_EMAIL@example.com and replace it with the email address where you want project inquiries sent.
3. Replace the LB initials block with a real profile photo if desired.
4. Replace sample portfolio concepts with real project screenshots, live links, and case studies. Do not present sample client testimonials as real reviews; replace them with genuine, approved feedback or remove that section.
5. Update the work-history descriptions and add accurate dates and outcomes.
6. The contact form currently prepares a message in the visitor's email app. For a production website, connect the form to your CRM or form backend (for example, a GoHighLevel form/workflow).
7. The hero background uses an externally hosted Unsplash image; an internet connection is needed to load it.

This is a responsive, self-contained HTML/CSS/JavaScript starter. It does not require a build step or framework.
